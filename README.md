# 💫 About Me

🔭 I've been building [**PitchPulse AI**](https://github.com/Faruk-Icn/PitchPulse-AI), a football experience that turns match events into tactical context for analysts and multilingual updates for fans.<br>
🌱 I'm exploring real-time systems, data visualization, and ways to make complex information feel simple.<br>
🎨 I also made a [**Mood Garden**](https://github.com/Faruk-Icn/Dear-Data-100-Project) that turns everyday waiting into flowers, patterns, and stories.<br>
💬 Ask me about football data, interactive experiences, or finding the human story in a dataset.
